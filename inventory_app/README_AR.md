# نظام الجرد - Android

نسخة أولى تعمل محلياً على الهاتف بدون إنترنت.

## الحساب الافتراضي
- اسم المستخدم: `admin`
- كلمة المرور: `1234`

## الوظائف الحالية
- تسجيل دخول
- لوحة تحكم وإحصائيات
- إضافة وحذف المنتجات
- أصناف مناسبة للبطاريات والألواح الشمسية والانفرترات
- إدخال وإخراج كميات المخزون
- منع إخراج كمية أكبر من المتوفر
- تنبيه المواد التي وصلت للحد الأدنى
- سجل كامل لحركات المخزون
- إضافة موظفين وحسابات دخول
- بحث بالاسم والصنف والكود
- تخزين محلي SQLite داخل الهاتف

## فتحه في Android Studio
1. افتح Android Studio.
2. اختر Open وحدد مجلد المشروع.
3. انتظر مزامنة Gradle.
4. من Build اختر Build APK(s).
5. ملف APK سيظهر عادة في: app/build/outputs/apk/debug/app-debug.apk

## ملاحظة
هذا المشروع لا يحتاج Firebase أو خادماً أو اشتراكاً في نسخته الحالية.
